# 種子資料與測試環境設定

## 概述

本文件定義最小的種子資料（Seed Data）、測試帳號設定、以及開發環境初始化流程，確保開發環境能順利跑通第一場對戰。

---

## 1. 種子資料策略

### 1.1 種子資料範圍

為了讓開發環境能跑通「最小可玩對戰」，需要以下種子資料：

| 資料類型 | 數量 | 說明 |
|---------|------|------|
| **測試帳號** | 2 個 | 玩家 A、玩家 B |
| **推しカード** | 2 張 | 各給 1 張 |
| **ホロメンカード** | 10 張 | Debut 等級，足夠組成 2 副牌 |
| **エールカード** | 5 種顏色 | 各 20 張（共 100 張） |
| **サポートカード** | 5 張 | 基本功能（抽牌、回復等） |

**不需要的資料**（後期再補）：
- 完整卡池（200+ 張卡）
- 進化卡（FIRST、SECOND 等級）
- 複雜效果卡片

## 3. Java 種子資料服務

### 3.1 `SeedDataService.java`

```java
package com.hololive.cardgame.seed;

import com.hololive.cardgame.entity.User;
import com.hololive.cardgame.entity.UserCard;
import com.hololive.cardgame.repository.UserRepository;
import com.hololive.cardgame.repository.UserCardRepository;
import lombok.extern.slf4j.Slf4j;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.ApplicationArguments;
import org.springframework.boot.ApplicationRunner;
import org.springframework.core.env.Environment;
import org.springframework.stereotype.Component;
import org.springframework.transaction.annotation.Transactional;

import java.util.Arrays;
import java.util.List;

@Slf4j
@Component
public class SeedDataService implements ApplicationRunner {
    
    @Autowired
    private Environment environment;
    
    @Autowired
    private UserRepository userRepository;
    
    @Autowired
    private UserCardRepository userCardRepository;
    
    @Override
    @Transactional
    public void run(ApplicationArguments args) {
        // 只在開發環境執行
        if (!Arrays.asList(environment.getActiveProfiles()).contains("dev")) {
            return;
        }
        
        log.info("開始初始化種子資料...");
        
        // 檢查是否已有測試帳號
        if (userRepository.existsByLineUserId("test_user_a")) {
            log.info("種子資料已存在，跳過初始化");
            return;
        }
        
        // 建立測試帳號
        createTestUsers();
        
        // 分配基礎卡片
        assignBasicCards();
        
        log.info("種子資料初始化完成！");
    }
    
    private void createTestUsers() {
        log.info("建立測試帳號...");
        
        // 玩家 A
        User userA = new User();
        userA.setLineUserId("test_user_a");
        userA.setDisplayName("測試玩家A");
        userA.setAvatarUrl("https://placehold.co/100x100?text=A");
        userRepository.save(userA);
        
        // 玩家 B
        User userB = new User();
        userB.setLineUserId("test_user_b");
        userB.setDisplayName("測試玩家B");
        userB.setAvatarUrl("https://placehold.co/100x100?text=B");
        userRepository.save(userB);
        
        log.info("✅ 測試帳號建立完成：{} (ID: {}), {} (ID: {})",
                 userA.getDisplayName(), userA.getId(),
                 userB.getDisplayName(), userB.getId());
    }
    
    private void assignBasicCards() {
        log.info("分配基礎卡片給測試帳號...");
        
        User userA = userRepository.findByLineUserId("test_user_a").orElseThrow();
        User userB = userRepository.findByLineUserId("test_user_b").orElseThrow();
        
        // 玩家 A：推しペコラ + 5 張ホロメン + エール
        assignCardsToUser(userA, List.of(
            "OSHI-001",       // 推しペコラ
            "HLM-001",        // ペコラ x 10
            "HLM-003",        // すいせい x 10
            "HLM-005",        // はあちゃま x 10
            "HLM-007",        // しおん x 10
            "HLM-009",        // あやめ x 10
            "SUP-001",        // 緊急補給 x 3
            "SUP-003",        // ファンレター x 3
            "SUP-004"         // スタッフさん x 4
        ));
        
        // 玩家 B：推しころね + 5 張ホロメン + エール
        assignCardsToUser(userB, List.of(
            "OSHI-002",       // 推しころね
            "HLM-002",        // ころね x 10
            "HLM-004",        // まつり x 10
            "HLM-006",        // あくあ x 10
            "HLM-008",        // ちょこ x 10
            "HLM-010",        // おかゆ x 10
            "SUP-002",        // 応援メッセージ x 3
            "SUP-003",        // ファンレター x 3
            "SUP-005"         // マネージャー x 4
        ));
        
        // エール（雙方都有）
        assignCheersToUser(userA, 20);
        assignCheersToUser(userB, 20);
        
        log.info("✅ 基礎卡片分配完成");
    }
    
    private void assignCardsToUser(User user, List<String> cardIds) {
        for (String cardId : cardIds) {
            UserCard userCard = new UserCard();
            userCard.setUserId(user.getId());
            userCard.setCardId(cardId);
            userCard.setCount(cardId.startsWith("HLM") ? 10 : (cardId.startsWith("SUP") ? 3 : 1));
            userCardRepository.save(userCard);
        }
    }
    
    private void assignCheersToUser(User user, int countPerColor) {
        List<String> cheerCardIds = List.of(
            "CHEER-WHITE", "CHEER-GREEN", "CHEER-BLUE", "CHEER-RED", "CHEER-PURPLE"
        );
        
        for (String cheerCardId : cheerCardIds) {
            UserCard userCard = new UserCard();
            userCard.setUserId(user.getId());
            userCard.setCardId(cheerCardId);
            userCard.setCount(countPerColor);
            userCardRepository.save(userCard);
        }
    }
}
```

### 4.2 測試帳號的 JWT Token

#### 手動產生測試 Token

```java
@RestController
@RequestMapping("/api/dev")
public class DevController {
    
    @Autowired
    private JwtTokenProvider jwtTokenProvider;
    
    @Autowired
    private UserRepository userRepository;
    
    /**
     * ⚠️ 僅在開發環境啟用
     * 產生測試帳號的 JWT Token
     */
    @GetMapping("/test-token/{lineUserId}")
    public ResponseEntity<String> generateTestToken(@PathVariable String lineUserId) {
        if (!Arrays.asList(environment.getActiveProfiles()).contains("dev")) {
            return ResponseEntity.status(403).body("此端點僅在開發環境可用");
        }
        
        User user = userRepository.findByLineUserId(lineUserId)
            .orElseThrow(() -> new RuntimeException("找不到使用者: " + lineUserId));
        
        String token = jwtTokenProvider.generateToken(user.getId(), user.getLineUserId());
        
        return ResponseEntity.ok(token);
    }
}
```

## 5. 開發環境初始化流程

### 5.1 首次啟動檢查清單

```bash
# 1. 確認 PostgreSQL 已啟動
docker ps | grep postgres

# 2. 確認資料庫已建立
psql -U postgres -c "\l" | grep holocardgame_db

# 3. 啟動 Spring Boot（會自動執行 Flyway Migration）
./mvnw spring-boot:run -Dspring-boot.run.profiles=dev

# 4. 檢查 Migration 是否成功
psql -U holocard_user -d holocardgame_db -c "SELECT * FROM flyway_schema_history;"

# 5. 檢查種子資料是否載入
psql -U holocard_user -d holocardgame_db -c "SELECT COUNT(*) FROM cards;"
# 預期：17 張（2 推し + 10 ホロメン + 5 サポート）

# 6. 檢查測試帳號
psql -U holocard_user -d holocardgame_db -c "SELECT * FROM users WHERE line_user_id LIKE 'test_%';"
# 預期：2 個測試帳號

# 7. 取得測試 Token
curl http://localhost:8080/api/dev/test-token/test_user_a

# 8. 測試建立對戰
curl -X POST http://localhost:8080/api/matches/create \
  -H "Authorization: Bearer {token}" \
  -H "Content-Type: application/json" \
  -d '{
    "oshiCardId": "OSHI-001",
    "deckCardIds": [...]
  }'
```

### 5.2 重置開發環境

若需要重置整個開發環境：

```bash
# 1. 停止 Spring Boot

# 2. 刪除資料庫
psql -U postgres -c "DROP DATABASE IF EXISTS holocardgame_db;"

# 3. 重建資料庫
psql -U postgres -c "CREATE DATABASE holocardgame_db OWNER holocard_user;"

# 4. 重啟 Spring Boot（會重新執行所有 Migration）
./mvnw spring-boot:run -Dspring-boot.run.profiles=dev
```

## 6. 管理介面與操作邊界

### 6.1 暫時使用 SQL 管理

在開發初期，使用 SQL 進行資料管理：

```sql
-- 查看所有卡片
SELECT * FROM cards ORDER BY card_type, card_id;

-- 查看玩家持有的卡片
SELECT u.display_name, c.card_name, uc.count
FROM user_cards uc
JOIN users u ON uc.user_id = u.id
JOIN cards c ON uc.card_id = c.card_id
WHERE u.line_user_id = 'test_user_a';

-- 新增測試卡片給玩家
INSERT INTO user_cards (user_id, card_id, count)
VALUES (
  (SELECT id FROM users WHERE line_user_id = 'test_user_a'),
  'HLM-001',
  5
);

-- 查看進行中的對戰
SELECT * FROM matches WHERE status = 'ACTIVE';

-- 強制結束對戰（測試用）
UPDATE matches SET status = 'FINISHED', winner_id = 1 WHERE id = 42;
```
