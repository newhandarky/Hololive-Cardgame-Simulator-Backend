## 一、目前進度摘要

本輪後端優化已從「單一 God Class 內補 helper」推進到「以 effect execution family 為單位拆出 package-private service」。

目前主要成果：

- `MatchEffectService` 已從萬行級逐步降到 `4,910` 行。
- 低風險 effect family 已多數移出主 service。
- Bloom / Collab dispatcher 已逐步改成直接依賴具體 execution service，減少回頭委派 `MatchEffectService` 的 bridge。
- `MatchActionService` 已開始 decision lifecycle 線，先抽出 pending decision store / creation service，並讓 look / reorder / draw reveal decision 進入 resolution service，降到 `5,377` 行。
- `MatchActionServiceIntegrationTest` 目前 `32,302` 行，暫不作為主線優先處理。

- AAA-233 已開始抽 `MatchDecisionResolutionService`，先搬 look / reorder 低耦合 decision handler。
- AAA-234 已搬 `DRAW_REVEAL` decision handler，保留 pending resolved、turn cheer 可用性判斷、main step gift follow-up 與 lifecycle confirm 行為。
- 下一批建議搬 `SEND_CHEER` decision handler；不要同批搬 `TRIGGER_EFFECT_CONFIRM` 與 `CARD_SELECTION`。

建議下一個 commit：

後端：搬移 MatchAction send cheer decision resolution

### 2. 繼續細分 `DAMAGE` 周邊高耦合 resolver

原因：

- `MatchDamageEffectExecutionService` 已承接 target resolution 後的 deterministic damage execution、summary、down 歸檔與 life loss orchestration。
- `MatchDamageEffectiveHpResolverService` 已承接 base HP、attached support HP bonus、self passive Gift HP bonus 快照解析。
- `MatchSpecialDamagePreventionResolverService` 已承接 SPECIAL_DAMAGE_IMMUNITY 查詢與 HSD13-012 stack cost 防護啟用。
- `MatchPassiveGiftIncomingDamageReductionResolverService` 已承接 passive Gift 受傷減免 target/holder 查詢、來源等級限制、骰子減免與 turn usage 紀錄。
- `MatchAttachedSupportIncomingDamageReductionResolverService` 已承接 attached support 受傷減免查詢與 base 文案解析。
- `MatchPassiveGiftHpChangePreventionResolverService` 已承接「相手能力不能改變 HP」的回合、target、holder 與條件解析。
- `MatchPassiveGiftArtBonusResolverService` 已承接 passive Gift 藝能加成 target/holder 查詢、特殊傷害加成、holder / target 條件與歷史推し技能條件解析。
- `MatchPassiveGiftArtCostReductionResolverService` 已承接 passive Gift 藝能費用減免 target/holder 查詢、art name、cheer color、attached support 與歷史推し技能條件解析。
- `MatchArtTextDamageBonusResolverService` 已承接藝能文案自體加傷 target context、Cheer / LIFE / 推し技能歷史 / 指定推し條件解析。
- `MatchArtDownTriggeredEffectExecutionService` 已承接藝能擊倒後 follow-up raw text 擷取、clause 解析、no-op summary 與 support effect 包裝。
- `MatchTriggeredGiftDamagePreventionExecutionService` 已承接 DAMAGE_RECEIVED Gift 受傷防護的 target / holder 查詢、turn usage、target / collab / dice 條件與 PREVENT_DAMAGE summary 組裝。
- `MatchTriggeredCombatEffectService` 已直接持有 `MatchArtDownTriggeredEffectExecutionService`，移除 `MatchEffectService.applyArtDownTriggeredEffects(...)` bridge。
- `MatchEffectTypeInferenceService` 已承接 Bloom / Collab / Gift / ArtDown 共用 effect type 與 target type 文案分類，dispatcher 與 triggered combat 不再透過 `MatchEffectService` 取得 target type 推斷。
- `MatchGiftEffectExecutionCoordinator` 已承接 Gift sequential-cost 判斷、cost / resolved effect 執行順序與 executed / unsupported / skipped summary 組裝。
- `MatchGiftEffectDispatcher` 已承接 Gift effect type switch routing；`MatchGiftEffectServiceHandlers` 只保留高耦合副作用 callback adapter。
- `MatchGiftArchiveReturnEffectExecutionService` 已承接 HBP02-039 / `REPLACE_ARCHIVE_WITH_HAND` 的 latest Holox `ATTACK_ART` payload 查詢、candidate summary、Archive -> Hand 移動與 no-op reason。
- `MatchGiftReattachEffectExecutionService` 已承接 `REATTACH` 的 dice / owner / target / source mode / Cheer row 搬移與 summary 組裝；Gift handler 已直接委派新 service。
- Bloom / Collab dispatcher 已直接持有 `MatchGiftReattachEffectExecutionService`，移除 `MatchEffectService.executeReattachEffect(...)` 薄 delegate。
- `MatchGiftAddCheerEffectExecutionService` 已承接 `ADD_CHEER` 的 raw text / resolved clause、`SendCheerAction` 執行、SQL fallback 與 summary 組裝。
- Bloom / Collab dispatcher、Gift handler 與 Support effect 入口已直接依賴 `MatchGiftAddCheerEffectExecutionService`，移除 `MatchEffectService.executeAddCheerEffect(...)` 薄 delegate。
- `MatchAddCheerTargetResolverService` 已承接 `ADD_CHEER` 目標子句擷取、區位 / 等級 / 名稱 / tag 條件、owned stage candidate 查詢與 restricted target no-fallback 規則。
- `MatchAddCheerSourceResolverService` 已承接 `ADD_CHEER` 來源子句擷取與 Archive / Cheer deck 來源選擇。
- `MatchGiftAddCheerEffectExecutionService` 已直接持有 `MatchAddCheerSourceResolverService` 與 `MatchAddCheerTargetResolverService`，移除 ADD_CHEER execution 專用 source / target functional callback interface。
- `MatchCheerCandidateQueryService` 已承接 `REATTACH` 與 `ADD_CHEER` source resolver 共用的 Cheer zone candidate 查詢，以及 `ADD_CHEER` 未指定來源時的 CHEER_DECK > ARCHIVE > HAND fallback attachable Cheer 查詢。
- `MatchGiftReattachEffectExecutionService` 已直接持有 `MatchAddCheerTargetResolverService`，移除 reattach execution 專用 target resolver callback interface。
