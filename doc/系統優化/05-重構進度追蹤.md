## 一、重新基準化結論

2026 年 5 月到 7 月完成的大量 extraction 已有效降低 `MatchEffectService`，並替 Bloom、Collab、Play Card、Attach Cheer、End Turn、Attack 與 decision lifecycle 建立多個 seam。這些成果保留，但舊的 AAA 編號序列不再作為下一步排程。

停止沿用舊排程的原因：

- 小 helper extraction 容易增加 service 數量，卻沒有降低 God Class 的依賴與 ownership。
- `service/` 已成為約 311 個檔案的平面目錄，繼續同模式會把單檔複雜度變成 package 複雜度。
- 前端尚未建立測試基線，且仍複製後端規則；只重構後端無法完成責任收斂。
- state version、PendingChoice 與 replay 都屬跨切面能力，必須在清楚 application boundary 上漸進導入。
